# Contributing

Thanks for your interest in improving this project! Contributions of all kinds are welcome: bug reports, feature ideas, docs, and code.

## Getting started

1. Fork the repository and clone your fork.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```

## Making changes

1. Create a branch from `main`:
   ```bash
   git checkout -b my-feature
   ```
2. Make your changes and keep commits focused.
3. Before opening a pull request, make sure the project lints and builds:
   ```bash
   npm run lint
   npm run build
   ```
4. Push your branch and open a pull request describing **what** you changed and **why**.

## Reporting bugs

Open an issue and include:
- What you expected to happen and what actually happened
- Steps to reproduce
- Your browser / OS / device (web, Expo Go, etc.)
